# Veylora website

A responsive starter website for Veylora, a student-led wellbeing society.

## Files
- `index.html` — page content and structure
- `style.css` — colours, layout and responsive styling
- `script.js` — mobile navigation and current year

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Upload all three website files (`index.html`, `style.css`, `script.js`) to the root of your GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Before publishing
- Replace `veylora@example.com` in `index.html` with an approved public contact email, or remove the email link.
- Confirm that all school names, claims, photos and contact details are approved for public use.
- Do not publish private student information or photos without appropriate permission.
