# Veylora website

A responsive public-facing website for Veylora — The GSIS Wellbeing Society.

## Files
- `index.html` — page content and structure
- `style.css` — lavender, soft green and cream styling
- `script.js` — mobile navigation and safe sharing-form preview
- `assets/veylora-logo.png` — logo extracted from the supplied Veylora logo PDF
- `assets/veylora-team.jpg` — group photo supplied for the website

## Publish with GitHub Pages
Keep all files and the `assets` folder in the repository root. In Settings → Pages, select Deploy from a branch, `main`, and `/(root)`.

## Before inviting people to use the sharing section
The form is only a front-end preview. It does not transmit or store messages. Connect a school-approved private form or support channel before collecting any personal concerns. Do not publish students' private details or contact information.

## Custom domain
A custom domain such as `veylora.com` or `veylora.in` must be registered separately, if available. Add the purchased domain in Settings → Pages → Custom domain and configure the DNS records required by GitHub Pages. Do not enter a domain you do not own.
